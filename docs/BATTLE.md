# BATTLE — 兼容索引

本文件保留用于兼容 T00～T14 的历史引用。战斗产品规则已收敛到 `COMBAT.md`；Phase 0 的当前实现、事件流与性能基线见 `ARCHITECTURE.md`、`CONFIG.md` 和 `CODEX_TASKS.md`。

以下内容是 Phase 0 灰盒验收基线，不扩展为后续版本范围。若与 `COMBAT.md` 冲突，以 `PRODUCT.md` → `COMBAT.md` → 本文件的顺序为准。

## 1. 开局

加载并校验配置，预热对象池，创建玩家和系统，HUD 清零。准备完成后战局从 `Booting` 进入 `Running`，计时与生成才开始。

## 2. 玩家移动与虚拟摇杆

- 触摸摇杆输出归一化二维意图 `[-1, 1]`；死区内为零，超出半径时夹紧。
- `PlayerMover` 以 `direction * moveSpeed * battleDeltaTime` 移动，不读取摇杆节点。
- 斜向速度不得高于轴向速度。玩家被限制在关卡可移动边界内。
- 触摸取消/抬起/组件禁用时必须清零方向，避免角色持续漂移。
- 编辑器可提供键盘调试适配器，与摇杆共同实现 `MovementInput` 接口。

## 3. 刷怪与追踪

- `MonsterSpawner` 按 wave 配置计算当前生成间隔、一次数量和怪物权重。
- 出生位置在玩家视野外的环带内，并被关卡边界夹紧；不得直接出生在玩家碰撞范围。
- 达到存活上限时跳过本次生成。恢复容量后按正常节奏继续，不一次补齐积压数量。
- 怪物以配置速度朝玩家当前位置移动。玩家/怪物无效或战局暂停时不更新。

## 4. 自动飞剑

- 武器仅在 `Running` 且冷却到期时查询目标。
- 默认目标规则：攻击半径内距离玩家最近的有效存活怪物；相同距离以稳定 `entityId` 决胜，确保可复现。
- 无目标时保留“可立即发射”状态，但以受控重试间隔查询，避免每帧全场扫描。
- 发射数量大于 1 时，对同一主目标采用小角度散射或依次选取，不引入复杂弹道系统。
- 飞剑命中、超时或越界后回池；每次激活对同一目标最多结算一次命中。

## 5. HP、伤害与死亡

- 伤害输入至少包含 `sourceEntityId`、`targetEntityId`、`amount`、`damageType`。
- MVP 伤害为非负整数，无暴击、护甲或元素克制；预留类型但不提前实现公式系统。
- `Health` 将生命夹紧在 `[0, maxHp]`。死亡转换只能发生一次；死亡后的伤害被拒绝。
- 怪物死亡顺序：标记死亡 → 从目标集合注销/停止碰撞 → 发布一次死亡事实 → 请求掉落 → 回收表现。

## 6. 经验掉落与拾取

- 每次有效怪物死亡产生配置指定的经验值。经验物位置来自死亡位置。
- 玩家进入拾取半径后经验物被收集；先标记已收集并停止碰撞，再发布一次经验事件并回池。
- 若经验物达到预算上限，把新经验合并到附近经验物或一个聚合掉落中；经验总量守恒。
- MVP 可先做立即拾取或直线吸附，磁吸曲线不是前置要求。

## 7. 等级与经验

- 累加经验后循环处理阈值，允许一次大额经验跨越多级，但同一时刻只展示一个升级面板。
- 若连续升多级，升级选择按队列逐个处理：选择一次后，如仍有待处理等级，刷新下一组三选一且保持暂停；全部处理完才恢复。
- 经验进度显示当前等级区间内进度，而不是累计总经验直接除阈值。

## 8. 升级暂停与三选一

- `ProgressionService` 生成三个不重复且当前可用的 option ID；固定随机种子时结果可复现。
- 候选不足三个时，由配置校验或明确的降级规则处理，不能死循环抽取。
- `BattleSession` 进入 `LevelUpPaused` 后才显示面板。面板点击具备防连点，首个合法选择胜出。
- `UpgradeService` 根据 option ID 修改玩家运行态，如：
  - `sword_damage_up`：基础伤害增加固定值或倍率。
  - `sword_cooldown_down`：发射间隔降低，但不得低于配置下限。
  - `sword_count_up`：每轮飞剑数量 +1，但不得超过上限。
- 应用成功后发布 `LevelUpResolved`。UI 不得直接修改武器组件字段。

## 9. 初始建议数值（仅用于灰盒）

| 项目 | 建议值 |
|---|---:|
| 玩家移动速度 | 320 unit/s |
| 飞剑伤害 | 10 |
| 飞剑发射间隔 | 0.8 s |
| 飞剑攻击半径 | 650 unit |
| 基础怪物 HP | 20 |
| 基础怪物速度 | 90 unit/s |
| 怪物经验 | 1 |
| 1→2 所需经验 | 5 |

这些数值必须落在配置中。目标是尽快验证闭环，不代表最终平衡。

## 10. 关键异常用例

- 最后一只目标在发射前死亡：重新校验目标，取消或改选，不攻击回池对象。
- 同帧多枚飞剑击杀同一怪物：只触发一次死亡和一份经验。
- 升级弹窗出现时仍有飞剑在途：模拟暂停，不继续位移或命中。
- 玩家升级时再次获得经验：正常队列化等级，不重复叠加面板。
- 场景退出时仍有监听/计时器：全部解除并回收，重新进入场景不重复触发。
