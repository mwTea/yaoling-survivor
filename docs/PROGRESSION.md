# PROGRESSION — 局外成长

## 1. 四条独立成长线

| 成长线 | 含义 | 主要来源 | 主要作用 |
|---|---|---|---|
| 玩家等级 | 账号长期活跃与内容进度 | 关卡结算、任务 | 功能/内容解锁、基础成长 |
| 境界 | 修仙阶段门槛 | 修为、突破条件 | 阶段属性、章节或培养上限 |
| 本命法器 | 主战攻击载体 | 灵石、材料、重复/专属资源 | 基础攻击、绝学、流派 |
| 灵兽 | 出战辅助与收集 | 灵魄、材料、活动/关卡 | 主动或被动技能、Build 补强 |

四条线不得共用含糊的“等级”字段；展示、存档、配置和埋点均使用明确命名。

## 2. 玩家等级

- 由账号经验提升，跨局永久保留；与局内战斗等级完全不同。
- 每级所需经验由连续等级曲线配置；满级后的经验处理需明确为停止累积、溢出保留或转换，首发前只能选择一种。
- 主要解锁功能、关卡与培养上限；基础属性提升应克制，避免成为唯一战力来源。

## 3. 境界、小境界、修为与突破

- 每个大境界包含有序小境界；修为填满当前小境界进度后进入突破条件判断。
- 普通小境界可自动或确认提升；大境界突破要求修为与可配置材料/关卡条件，必须有预览与确认。
- 突破只消耗页面明确列出的资源；失败机制默认不采用。若未来引入概率，必须单独产品评审并提供保底与透明概率。
- 境界提升可开放属性、功能或内容门槛，但不可与玩家等级互相替代。

## 4. 本命法器

首批规划五件：

| 法器 | 基础攻击行为 | 绝学/流派方向 |
|---|---|---|
| 青霄剑 | 自动索敌飞剑/剑气 | 高频、多剑、穿透或御剑 |
| 摄魂笛 | 音波/持续范围攻击 | 控制、削弱、召魂联动 |
| 乾坤仪 | 环绕或轨道法器 | 防御、牵引、范围循环 |
| 离火扇 | 扇形火焰/灼烧 | 持续伤害、扩散、爆燃 |
| 镇妖铃 | 周期震荡/标记 | 击退、眩晕、对精英/Boss 强化 |

- 每件法器拥有稳定 ID、等级、解锁状态、基础攻击定义、绝学节点和流派标签。
- 法器等级为局外永久养成，提升基础参数或解锁节点；局内三选一只修改当局运行态。
- 绝学是法器的高辨识度能力，可由法器等级/突破与局内条件共同激活；首发具体数量与效果在 V0.1 内容表确定。
- 流派用于描述可组合方向，不等同于复杂羁绊系统；V1.0 不建立庞大天赋树。
- Phase 0 的 `weapon_flying_sword` 是青霄剑方向的技术原型，不代表正式数值或完整法器系统。

## 5. 灵兽

首批规划：青龙、白虎、朱雀、玄武、九尾狐。每只灵兽包含解锁状态、等级、星级、灵魄、技能和出战状态。

- **等级**：消耗通用/专属养成资源，提升基础效果；受玩家等级或境界上限约束。
- **星级**：消耗该灵兽灵魄或明确的通用替代物，提升技能阶段或成长上限。
- **灵魄**：灵兽碎片型资源，来源和转换规则在 `ECONOMY.md` 定义；禁止无说明地跨灵兽互换。
- **技能**：区分出战主动/触发技能和持有被动；技能目标、冷却和数值配置化。
- **出战**：首发默认单灵兽出战，编队容量必须由版本明确解锁；未出战灵兽不默认提供复杂羁绊。

## 6. 战力与门槛

战力可作为养成汇总与建议，不作为战斗真实结算公式，也不替代关卡推荐。章节门槛优先使用明确进度条件；若展示推荐战力，应标注仅供参考并可通过技巧/Build 越级。

## 7. 数据与重置

- 升级、突破、升星必须为可审计事务：校验条件 → 扣除资源 → 更新状态 → 发放/解锁 → 保存。
- 默认不提供误导性的随机培养。重置/返还若开放，返还比例和不可退项目必须预览。
- 配置升级不得降低已拥有等级/星级；删改内容需迁移策略。

## 8. 当前实现

Phase 0 只实现局内战斗等级与三种飞剑升级效果；玩家等级、境界、正式法器培养和灵兽均未实现。完整成长线归属 V0.5，禁止借文档重构接入代码。
