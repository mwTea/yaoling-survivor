# PRODUCT — 产品总纲

## 1. 产品定位

《妖灵修行录》是一款面向微信小游戏的竖屏、单局自动战斗、生存割草与局外修仙养成结合的轻量游戏。玩家通过走位、局内三选一和 Build 组合完成关卡，再用获得的资源提升玩家、法器与灵兽，逐步挑战新章节与更高难度。

目标体验：上手直接、单局成长明显、构筑有选择、局外进展可预期；适合碎片时间，同时保留中长期收集与养成目标。

## 2. 三条体验支柱

1. **走位与生存**：自动攻击不等于无操作，聚怪、躲避和拾取路线影响胜负。
2. **构筑与爆发**：局内功法、法宝和升级三选一形成可辨识 Build，选择立即改变战斗表现。
3. **修行与收集**：玩家等级、境界、本命法器和灵兽提供稳定的局外成长与内容目标。

## 3. 产品核心循环

```text
选择章节/关卡与出战配置
  → 单局战斗（移动、自动攻击、击杀、拾取、升级三选一、精英/Boss）
  → 结算星级、掉落与任务进度
  → 局外培养（玩家/境界/法器/灵兽）与收集
  → 解锁更高章节、难度和内容
  → 再次挑战
```

短期目标来自通关、三星和日常任务；中期目标来自境界突破、法器/灵兽培养和图鉴；长期目标来自章节推进、收集完成度和持续内容更新。

## 4. 局内与局外的严格边界

| 领域 | 局内（单局临时） | 局外（账号持久） |
|---|---|---|
| 成长 | 战斗等级、当局功法/法宝、三选一、Build | 玩家等级、境界/修为、本命法器等级、灵兽等级/星级 |
| 资源 | 经验物、当局效果、临时计数 | 灵石、灵玉、修为、灵魄、养成材料 |
| 生命周期 | 开局初始化，结算后清空 | 写入存档，可迁移、校验和恢复 |
| 配置输入 | 已选本命法器、出战灵兽、关卡规则 | 解锁、培养、编队、库存与领取状态 |

- 局内经验只提升当局战斗等级，不等同于玩家等级或修为。
- 局内功法/法宝默认不永久拥有；结算仅发放明确配置的局外奖励。
- 局外属性只能通过战斗快照/明确接口注入，不允许战斗过程中直接改账号存档。
- 战斗失败、退出、复活和结算的奖励规则必须由关卡配置显式定义。

## 5. 完整设计与当前实现

> **设计到 ≠ 当前开发。** 本文档体系描述完整产品方向，用于统一名词、边界和扩展点；实际开发只按 `ROADMAP.md` 当前阶段和 `CODEX_TASKS.md` 明确任务执行。

当前代码是 **Phase 0（T00～T14）核心战斗技术验证**。其灰盒飞剑、基础怪物、经验升级与三选一是验证底座，不代表完整产品内容已实现。此次 V0.2 是文档体系版本，不是可玩版本号，也不授权开发任何新系统。

## 6. 首发平台与商业边界

- 首发：微信小游戏，竖屏单手优先；适配小屏、刘海/圆角和 SafeArea。
- V1.0 前不以付费墙阻断主线基础进度，不出售只能付费获得的战斗胜利。
- 广告以玩家主动触发的激励视频为主，可用于可选复活、额外结算或资源补充；不得伪装按钮、强迫连续观看或破坏未成年人/平台合规。
- 插屏、支付、礼包价格和投放频率必须经正式商业化评审与配置开关控制；Phase 0 不接入广告或支付。

## 7. 内容与非目标

V1.0 产品范围由 `ROADMAP.md` 分阶段交付。以下系统进入 **Future**，除非为数据/接口预留扩展点，不进入 V1.0：经脉、复杂羁绊、装备洗练、宝石、公会、PVP、多人、赛季、通行证、离线挂机。

首发也不承诺开放世界、重剧情、实时社交或跨端复杂账号体系。任何新增系统必须说明服务哪条体验支柱、归属版本、依赖和可独立验收范围。

## 8. 文档地图与优先级

- `GAME_LOOP.md`：单局、局外和解锁节奏。
- `PROGRESSION.md`：玩家等级、境界、法器、灵兽。
- `COMBAT.md`：战斗、功法、法宝、Build、时间系统。
- `CONTENT.md`：怪物、章节、关卡、难度、奖励内容。
- `ECONOMY.md`：资源、产消、商店和礼包模型。
- `RETENTION.md`：任务、登录、成就、图鉴、奖励中心。
- `UI_IA.md`：页面与战斗 UI 信息架构。
- `LIVEOPS.md`：活动、红点、服务器时间、功能开关与运营边界。
- `ROADMAP.md`：版本范围和 Future。

冲突优先级：用户当前明确要求 → `AGENTS.md` → 本文件 → `ROADMAP.md`（版本范围）→ 对应专题文档（系统规则）→ `ARCHITECTURE.md` / `CONFIG.md` → 当前实现。当前实现事实与验收状态以 `CODEX_TASKS.md`、`MILESTONES.md` 为准；不得用远期设计覆盖已验证事实。
