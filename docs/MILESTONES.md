## M0：仓库与工程可启动

状态：已完成（2026-09-20）。

验收：

- 仓库骨架、`AGENTS.md` 与核心文档齐全且互不冲突。

- `BattleScene` 可打开、预览和重新进入，无控制台错误。
- 缓存/构建产物未被 Git 跟踪。

状态：已完成（2026-09-20）。键盘移动与虚拟摇杆均通过 Creator 验收；微信开发者工具与真机触控验证明确保留到 T14，不计入当前桌面灰盒阻断项。

验收：

- 暂停战斗模拟时玩家停止，UI 输入仍可用。

## M2：怪群追踪与池

状态：已完成（2026-09-20，T05–T07 全部通过 Creator 验收；池容量自 T07 起由 stage.activeMonsterHardCap 驱动）。

验收：

- 配置校验通过后按波次在视野外生成基础怪物。
- 怪物追踪玩家，暂停时停止，恢复时继续。

## 非阻断观察项

手感、美术、音效和平衡问题可记录为后续观察，但不应偷偷扩成第一阶段系统。阻断项是闭环不可完成、状态错误、数据重复结算、明显泄漏或低于性能基线。
